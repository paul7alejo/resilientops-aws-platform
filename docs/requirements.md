# Initial requirements

- No public database or unnecessary public administration interface.
- Least-privilege access using roles where possible.
- Encryption for stored data and protected secrets.
- Centralized audit logging and useful operational alerts.
- A documented incident-response and recovery process.
- Infrastructure managed and reviewed with Terraform.
- Synthetic data only.
- Short-lived or low-cost AWS resources during experimentation.
- Every major decision recorded as: problem, decision, implementation, test, result, trade-off.
